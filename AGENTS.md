# Working in this repo

- After making changes, always commit and push to `main`. Hostinger auto-deploys from `main`.
  (Standing instruction from the owner.)
- The site is static HTML, CSS and a little plain JavaScript. No build step, no library. Every section
  must stay readable and usable when JavaScript or motion is off.
- The look follows `BRAND.md` and the Claritia design system (https://claude.ai/artifact/2ZKbX3ATfS3Fr7LnEVTUkA).
- The header, phone menu and footer live in `index.html`. `tools/shell.py` copies them into every generated page, so
  after changing them run `python3 tools/templates.py && python3 tools/legal.py`.
- `templates/` (the form template gallery) is generated by `tools/templates.py` from `tools/templates.json`. Edit the
  generator or the data, never the pages.
