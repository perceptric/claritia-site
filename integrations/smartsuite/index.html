How it works

Connect SmartSuite in a few minutes

  1. 01

    Connect SmartSuite

    Go to Settings, then Integrations, and paste your SmartSuite API key and workspace.

  2. 02

    Pick the table

    Open the form's Sync tab, add SmartSuite and pick the table.

  3. 03

    Publish

    Each new fill shows up in SmartSuite as a record.
