How it works

Connect Cal.com in a few minutes

  1. 01

    Add Cal.com in Claritia

    Go to Settings, then Integrations, add Cal.com and copy the webhook address.

  2. 02

    Paste it in Cal.com

    In Cal.com, open Settings, then Developer, then Webhooks, and add the address.

  3. 03

    Done

    Each new booking comes into Claritia.
